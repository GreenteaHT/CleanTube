## 할 일

- [ ] 사용자 브라우저에서 확인. 로그인 상태에서 디버그 패널을 켜고 차단/해제, 팝업으로 @핸들 입력. 2026-10-05에 빌드한 확장기능을 로그아웃 헤드리스 크롬에 올려 최상위 댓글, 답글, 스크롤로 뒤늦게 붙는 댓글, 다른 영상으로 이동한 뒤, 패널의 차단/해제, 팝업 토글까지는 확인했다. 로그인 상태는 아직이다
- [ ] 디버그 패널 다듬기. 쓰면서 불편한 점을 모은다. 후보: 같은 작성자 묶기, 숨긴 댓글만 보기, 접힘 상태 기억
- [ ] `utils/matcher.ts` 단위 테스트. vitest 추가. 핸들의 대소문자와 @ 유무, 채널 ID의 대소문자, 빈 문자열
- [ ] 매칭 규칙 확정. 지금은 정확 일치다. 채널명 매칭이 빠지면서 "김 철수" 같은 띄어쓰기 문제는 없어졌다
- [ ] 스캔 스케줄링 실측. 150ms 디바운스는 임시값. 스크롤 시 MutationObserver 콜백 횟수, applyAll 소요 시간, 간격별 체감 지연을 재고 나서 디바운스 간격, requestAnimationFrame, IntersectionObserver 중에서 정한다
