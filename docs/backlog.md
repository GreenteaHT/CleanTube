## 할 일

- [ ] 로그인 상태에서 확인. 표시 방법 세 가지와 "숨긴 항목 보기", 임시 차단 메뉴와 팝업의 기간 설정, 유튜브 ⋮ 왼쪽에 놓인 우리 버튼, 목록에서 차단한 경위 펼쳐 보기. 2026-10-06까지 로그아웃 헤드리스 크롬에서는 전부 확인했다. 버튼 위치는 ⋮의 hidden을 풀어 흉내 낸 것이다
- [ ] 차단된 댓글의 메뉴에서는 경우에 따라 "차단 해제"가 차단 항목을 대체한다. 지금은 차단된 댓글에서도 메뉴에 영구 차단과 임시 차단이 그대로 나오고, 해제는 패널이나 팝업에서만 된다. 어떤 경우에 바꿀지는 만들 때 정한다
- [ ] 차단할 때 숨김과 흐리게에도 애니메이션. 지금은 완전히 숨기기만 접히는 애니메이션이 있고, 흐리게와 "차단된 댓글"로 바꾸기는 바로 바뀐다
- [ ] 첫 사용 안내. 처음 쓸 때 튜토리얼처럼 표시 방법 같은 설정을 자연스럽게 고르고 시작하게 한다. 사용자가 나중에 하겠다고 했다
- [ ] 댓글 메뉴 항목 늘리기. 무엇을 넣을지는 사용자가 정한다
- [ ] 디버그 패널 다듬기. 쓰면서 불편한 점을 모은다. 후보: 같은 작성자 묶기, 차단된 댓글만 보기, 접힘 상태 기억
- [ ] 스캔 스케줄링 실측. 150ms 디바운스는 임시값. 스크롤 시 MutationObserver 콜백 횟수, applyAll 소요 시간, 간격별 체감 지연을 재고 나서 디바운스 간격, requestAnimationFrame, IntersectionObserver 중에서 정한다. 새로 붙은 댓글을 즉시 처리할 때 페이지 세계가 모든 댓글을 다시 훑는 비용도 같이 잰다
